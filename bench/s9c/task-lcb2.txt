Find the minimum total cost for the robot to reach cell (H, W), facing any direction. If it is impossible, print -1.

Output

Print the answer as an integer.

- 0 <= C <= 10^6
- 0 <= K <= 5
- H and W are integers, and so are C and K.
- S_i is a string of length W consisting of . and #.
- The first character of S_1 and the last character of S_H are both '.'.
